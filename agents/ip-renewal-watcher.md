# IP Renewal Watcher（中国知识产权期限监控智能体）

## 目标

作为后台运行的 scheduled agent，每日（工作日）上午 9:00 自动扫描中科三清知识产权组合数据库，识别即将到期或已逾期的专利年费、商标续展、软著登记、集成电路布图设计期限，生成风险分级报告并推送至指定通知渠道。

## 监控范围

| 资产类型 | 监控事项 | 红灯阈值 | 黄灯阈值 | 蓝灯阈值 |
|:---|:---|:---|:---|:---|
| **发明专利** | 年费缴纳 | 已逾期 / 滞纳期最后15天 | 30天内到期 | 90天内到期 |
| **实用新型专利** | 年费缴纳 | 已逾期 / 滞纳期最后15天 | 30天内到期 | 90天内到期 |
| **外观设计专利** | 年费缴纳 | 已逾期 / 滞纳期最后15天 | 30天内到期 | 90天内到期 |
| **注册商标** | 续展申请 | 已过期 / 宽展期最后15天 | 30天内到期 | 90天内到期 |
| **软件著作权** | 版本迭代登记 | 新版本发布超6个月未登记 | 新版本发布超3个月未登记 | 新版本发布 |
| **集成电路布图设计** | 登记期限 | 已超10年保护期 | 保护期剩余1年 | 保护期剩余2年 |

## 执行逻辑

### Step 1: 读取组合数据库

**数据源优先级**：
1. 主数据源：企业内部知识产权管理系统（如 incoPat 企业版、大为、彼速等）导出的 CSV/XLSX
2. 备用数据源：从 CNIPA 专利缴费系统、商标局网上服务系统手动更新的记录
3. 外部校验：通过 incoPat/智慧芽 API 批量校验法律状态（每周一次）

**数据字段要求**：

### Step 2: 期限计算与风险分级

#### 2.1 专利年费计算

```python
# 伪代码逻辑
def calculate_patent_risk(asset):
    today = datetime.now()
    deadline = asset.next_deadline
    days_until = (deadline - today).days
    
    if asset.status == "lapsed":
        return "RED", "权利已终止"
    
    if days_until < 0:
        # 已逾期，计算滞纳期
        grace_period_end = deadline + timedelta(days=180)
        days_in_grace = (today - deadline).days
        if today > grace_period_end:
            return "RED", f"已超滞纳期，权利终止（逾期{days_in_grace}天）"
        else:
            return "RED", f"已逾期，滞纳期第{days_in_grace}天（剩余{180-days_in_grace}天）"
    
    if days_until <= 15:
        return "RED", f"紧急：仅剩{days_until}天"
    elif days_until <= 30:
        return "YELLOW", f"预警：仅剩{days_until}天"
    elif days_until <= 90:
        return "BLUE", f"提醒：剩余{days_until}天"
    else:
        return "GREEN", f"正常：剩余{days_until}天"
```

#### 2.2 商标续展计算

```python
def calculate_trademark_risk(asset):
    today = datetime.now()
    deadline = asset.next_deadline  # 注册有效期满日
    days_until = (deadline - today).days
    
    if asset.status == "lapsed":
        return "RED", "商标已注销"
    
    if days_until < 0:
        # 宽展期
        grace_period_end = deadline + timedelta(days=180)
        if today > grace_period_end:
            return "RED", "已超宽展期，商标注销"
        else:
            return "RED", f"宽展期内（剩余{(grace_period_end - today).days}天，须加收延迟费）"
    
    if days_until <= 15:
        return "RED", f"紧急：仅剩{days_until}天"
    elif days_until <= 30:
        return "YELLOW", f"预警：仅剩{days_until}天"
    elif days_until <= 90:
        return "BLUE", f"提醒：剩余{days_until}天"
    elif days_until <= 365:
        return "GREEN", f"正常：剩余{days_until}天，建议本季度安排续展"
    else:
        return "GREEN", f"正常：剩余{days_until}天"
```

## 异常处理

| 异常场景 | 处理逻辑 |
|:---|:---|
| 数据源更新失败 | 使用上次成功数据，标记"数据可能过期"，通知 IT 排查 |
| 资产状态冲突（外部显示终止，内部显示有效） | 标记"状态冲突"，优先按外部数据预警，要求人工核实 |
| 费减资格到期未更新 | 按全额计算年费，标记"费减状态待确认" |
| 代理所联系方式变更 | 从代理所名录读取最新信息，若缺失则标记"联系信息待更新" |
| 节假日调整 | 若到期日为节假日，提前至最后一个工作日预警 |
| 批量逾期（>5件红灯） | 升级为紧急事件，立即通知知识产权总经理 + 总裁助理 |

## 合规与安全

1. **数据保密**：组合数据库含未公开专利申请信息，存储和传输须加密，访问权限限于知识产权部 + 财务部门
2. **数据不出境**：若使用公有云服务推送通知，确保通知内容不含具体技术信息（仅含申请号、名称、金额）
3. **审计日志**：记录所有期限变更、缴费操作、放弃决策，保存至少 10 年（与专利档案同周期）
4. **人工复核**：AI 生成的维持/放弃建议仅供参考，最终决策须由知识产权经理签字确认
